# Ícone orçamento.

Verde profundo, barras em verde-claro e o ponto da marca. A arte original está em source.png.

| Arquivo | Uso |
| --- | --- |
| app-store-1024.png | Arte quadrada opaca para catálogo de ícones do Xcode / App Store |
| google-play-512.png | Listagem da Google Play, PNG RGBA de 512 px, abaixo de 1 MB |
| icon-192.png / icon-512.png | App web instalado (PWA) |
| icon-maskable-512.png | PWA com máscara aplicada pelo sistema |
| apple-touch-icon.png | Tela inicial do iPhone/iPad, 180 px |
| favicon.ico | Navegadores, tamanhos 16, 32 e 48 px |
| favicon-16.png / favicon-32.png / favicon-48.png | Versões PNG para navegador |

Os arquivos mantêm os cantos quadrados para que cada sistema aplique sua máscara. O símbolo fica centralizado com margem para recortes circulares. As exportações das lojas são artes estáticas; integração em projetos nativos e publicação nas lojas não estão incluídas. Um projeto Android nativo ainda deve configurar seu launcher/adaptive icon.

Referências de formato: [Apple — catálogo de ícones](https://developer.apple.com/documentation/xcode/configuring-your-app-icon), [Google Play — especificações](https://developer.android.com/distribute/google-play/resources/icon-design-specifications).

O prompt e o modo de geração estão em PROMPT.md.
